# Shayma & Bilal — Fiançailles

Invitation en ligne : https://shayma-et-bilal.github.io

- Infos de la soirée (date, heure, lieu, adresse, WhatsApp, musique) : `config.js`, sans rien recompiler.
- Musique de fond optionnelle : déposer le fichier dans `assets/musique.mp3`.
- Code source : `src/` (Three.js, GSAP, Lenis). Après modification : `npm install && npm run build` (génère `dist/main.js`).

Sources des textes : versets (texte arabe et traduction Muhammad Hamidullah) via quran.com ; hadiths et jugements d'authenticité via la base hadith-api (fawazahmed0), les traductions marquées « trad. libre » sont rédigées pour l'invitation. Images : NASA Scientific Visualization Studio, « CGI Moon Kit » (SVS 4720) et « Blue Marble » (SVS 2915).
